# P7 (M5 map workstream) - THE Sim.Ui RAW-READ ALLOWLIST, read by BOTH scripts/check-read-isolation.sh (the advisory
# grep, CI) and Sim.Ui.Tests KnowledgeLeakTests (the source guard). One list, two readers - never edit a copy.
#
# What is matched: a read of a foreign-sensitive world table - Settlements, MilitaryUnits, Buckets, Deposits or (M6 EX)
# the discovery tables KnownExtents, Explorations, SettlementSightings, SettlementSurveys - through
# a world receiver (world, w, _world, World, prev, next, W) in Sim.Ui/**/*.cs. Any file that does so must be listed here
# with its CLASS and a reason; a new raw read anywhere else fails both readers.
#
# Classes (the source guard checks the first one mechanically):
#   routed     - a player-facing reader that asks PlayerKnowledge before it reads a settlement's or a formation's rows
#                (the file must reference PlayerKnowledge); its non-interference is pinned by the metamorphic tests
#   seam       - the knowledge view itself
#   own        - reads only the player's own settlements (or the table's row count), never a foreign row's content
#   developer  - a developer surface (DEV > TURN / RECORDS), deliberately unfiltered, like the developer export
#   geometry   - a position for the camera, asked for a settlement the caller already holds (the selection)
#   harness    - headless tooling (the gate, its stub, the frame-cost bench, the SVG previews), never a player surface
#
# Format: <path> | <class> | <reason>
Sim.Ui/ViewModel/PlayerKnowledge.cs | seam | the per-turn view over the Sim.Core seam: it enumerates settlements to cache KnowsSettlement
Sim.Ui/World/WorldLens.cs | routed | WorldProjection.Build: the observer; hidden settlements, formations, territory, paths and routes are never visited
Sim.Ui/World/TerrainMarks.cs | routed | M6 E1.3 FieldsOf: the site of a cultivating settlement whose books the player reads, and only its catchment nodes the PlayerKnowledge knows
Sim.Ui/ViewModel/SettlementSelection.cs | routed | Tab cycles known settlements only; the opening selection is the first known one
Sim.Ui/ViewModel/HudModel.cs | routed | a hidden selection reads as none; the band totals (population, food, settlement count) read the player's OWN settlements only (EmpireStores.OwnSettlements), never a foreign one
Sim.Ui/ViewModel/PlayerViews.cs | routed | a hidden settlement reads as absent; formations, migration and trade lines name known subjects only
Sim.Ui/ViewModel/StateChronicle.cs | routed | annal events are kept only when every settlement and polity they name is known
Sim.Ui/ViewModel/UnitCardModel.cs | routed | an unknown formation has no card
Sim.Ui/ViewModel/NeedsPanelModel.cs | routed | a hidden settlement reads as one with nobody present
Sim.Ui/ViewModel/HistoryBuffer.cs | routed | the world series sum known settlements; per-settlement series are cached for every settlement and read through the knowledge (a hidden settlement's price series is no data)
Sim.Ui/Actions/ActionSurfaceModel.cs | own | adults of the player's controlled settlements (the labour summary)
Sim.Ui/UiSession.cs | own | the settlement row COUNT, to rebuild the name registry after a founding (never displayed)
Sim.Ui/ViewModel/ScreenModels.cs | developer | DEV > RECORDS: the selected settlement's class buckets for the explain views; the selection-keyed views (Settlement, Policy) read a hidden settlement as no selection
Sim.Ui/ViewModel/TurnAuditModel.cs | developer | DEV > TURN: the founded-settlement count of the turn audit
Sim.Ui/ViewModel/CameraFocus.cs | geometry | the site of the settlement the caller centres on (the selection, a WHERE row)
Sim.Ui/ViewModel/OverlayMeshes.cs | geometry | overlay mesh helpers no renderer calls any more (WorldLayerOwnershipTests); kept for their tests

Sim.Ui/Headless/PlayabilityGate.Placement.cs | harness | the gate's placement rows (S1d) and the placement state's rig: the source's own site (an illegal place) and where a hidden settlement stands (undiscovered ground offered nothing), and the rig's check that its order founded
Sim.Ui/Headless/MapFrameCost.cs | harness | the map frame-cost bench (--frame-cost map)
Sim.Ui/Theme/EraPreview.cs | harness | the era SVG preview tool
