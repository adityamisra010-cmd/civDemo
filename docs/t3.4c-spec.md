## Item 1 — the variance fix (ruling 1)

`HarvestWeatherSystem` builds the regional field with **self-weight `w_ii = 1.0`**, so `regional[i]`
contains `local[i]`, and then blends them as though independent:

```
innovation = √k·regional_i + √(1−k)·local_i
Var(innovation) = 1 + 2√(k(1−k))/√sumSq_i        ← not 1
```

Confirmed by four independent derivations and isolated conclusively by the k-sweep: **exact at k=0
and k=1, maximal in between, shipped k=0.6 at the maximum.**

**The fix, two lines inside the existing Pass 3, reusing `sumSq_i` from Pass 2:**

```
varInn_i   = 1 + 2·√(k(1−k))/√sumSq_i        // (√k+√(1−k))² on the no-route fallback branch
innovation = (√k·regional_i + √(1−k)·local_i) / √varInn_i
```

Exact for every geometry including n=1 and the degenerate no-neighbour case. Restores `E[mult] = 1`
and `sdLog = σ` identically. Leaves spatial structure, temporal structure, draw order and RNG
consumption untouched. **σ stays 0.2936** — it becomes correct once the substrate delivers it.

**Rejected alternative, recorded so it is not re-proposed:** excluding self (`w_ii = 0`) does make
them independent, but fires the `sumSq == 0` fallback for any settlement with no reachable
neighbour — landing exactly on the 1.407× worst case — and changes what "regional" means.
