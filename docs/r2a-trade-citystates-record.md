## 1. The Trade node (decisions 1, 13, 14) — IMPLEMENTED

| field | value |
|---|---|
| id / key | `trade` / 426 (appended after `motor_road`; no renumbering) |
| tree / branch | Technology, Main (trunk) — "add … to the Technology research tree" (L1) |
| Age | A3 (Bronze Age) — its carriers (`donkey`, `camel`, `sail_square`) are A3 |
| prerequisite | `token_counting AND (donkey OR camel OR sail_square)` — a record of quantity plus a carrier of goods over distance; depth 6 |
| cost | 880 RP — banded model T2, magnitude 3.25 (novelty 1.0, difficulty 0.5, material 0, institutional 0.75, breadth 0.5, prereq 0.5), = arithmetic_babylonian |
| Eureka | none (no evaluable condition the corpus pattern supports that the prerequisites do not already imply) |
| consequence | entity `activity.trade` (kind activity, requires `trade`) ← sim.json `trade.entity` |
| enforcement | `TradeArbitrageSystem` moves goods between a pair only when `TradeQuery.CanTrade` holds on PREV: BOTH endpoints' settlement knowledge (`SettlementKnowledge.MaskOf`) makes the entity eligible. No node id in C#. |
| order | none: arbitrage is automatic once legal (no trade order exists; none invented). "Initiation" is the research directive (OrderKind 6); a hand-built directive for an unavailable `trade` is refused (`ResearchQuery.TargetOrder` returns null; ResearchSystem ignores it). |
| UI | AvailableActionsQuery domain 11 `Trade` (Standing, targets = the issuer's settlements where trade is legal), shown in the action surface's "On their own" list; announced as "new: Trade" by the generic notice. Not listed before the research. |
| audit | `docs/research-gameplay-unlock-audit.md` consumer type `trade` (class B, LIVE), regenerated by its script; `--check` passes |
| tests | `TradeResearchUnlockTests` T01–T07, T09; `ResearchUnlockPipelineUiTests.Trade_AppearsOnTheSurface_OnlyWhenLegallyAvailable` |

**Placement rationale.** Civ VI (L5): trade routes and the Trader unit are unlocked by the Ancient-Era civic
**Foreign Trade**, whose prerequisite is Code of Laws; the Market comes with the Currency technology (after Writing).
Sources: <https://civilization.fandom.com/wiki/Foreign_Trade_(Civ6)>, <https://www.civilopedia.net/en-US/rise-and-fall/civics/civic_foreign_trade/>,
<https://civilization.fandom.com/wiki/Trader_(Civ6)>. Ours is similar — an early, cheap node — but placed causally
on our corpus: formal trade between communities needs counted value (`token_counting`, "record of quantity
without memory" — the tokens were commodity accounting) and a way to move goods (the pack animal or the sail).
It is deliberately NOT after `standard_weights`/`proto_writing` (that would make trade a late Bronze-Age node,
later than Civ VI's position) and NOT behind `coinage_electrum` (money is a later refinement of exchange).
One node, no barter/local/foreign split (decision 13). Baseline exchange inside a settlement is not trade in this
code (TradeArbitrageSystem is the only inter-settlement goods mover) and is unaffected.

**Combined effect with R1 (MEASURED).** R1 already left the order-free founded world with no trade in 300 turns
(nothing to trade before pottery/bronze). R2a adds a second gate: a dev-world realm that KNOWS its crafts
moves 0 units in 30 turns without Trade (T01) and > 0 with it (T02); the post-Trade preview moves 8 units in its
last turn. The order-free founded golden and first-reign golden are unmoved (their worlds already traded nothing).

## 2. City-states (decisions 4, 12) — IMPLEMENTED

Design note `docs/city-state-progression.md` (written before the code). Settlement-scoped knowledge holder key
`PolityId(−1 − s)` in the existing research tables; the same ResearchSystem loop; target = cheapest available
node; RP = 0.25 × the RP curve of its own population (`research.json tuning.cityStatePaceFraction`, TUNE, L6).
Settlement knowledge = controller's ∪ own; the controller is not granted the city's knowledge (OPEN: diffusion).
No schema change (v31). Tests `CityStateProgressionTests` C1–C6 + populated-table + inertness.
MEASURED (preview): a city-state released at founding on the canonical world reaches 8 nodes in 600 turns
(10.5 RP/turn at 7,797 people), its food sector now expresses Farming through its own Root-and-tuber knowledge.

## 3. Turn-1 economy (decision 8) — STOPPED at the calibration gate

Implemented behind an isolated content switch, `sim.json farming.preCultivation` (**committed `enabled: false`**):
before the settlement's knowledge makes `activity.farming` eligible, the Farming sector harvests wild food at
**1.0 person-years per fertility-weighted km²** and **2.0 per gatherer** (forager reference class — Binford 2001,
Kelly 2013, Kroeber 1939 — fixed in sim.json before measuring, CR-003 §5.1); the CR-003 26.0 / 5.0 apply once
farming is known. MEASURED with the switch ON (Release, this branch):
