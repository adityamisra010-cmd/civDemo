  state per settlement) — do NOT raise the variance to force the spread.

## Reference classes — FIXED BEFORE ITEM 0 REPORTS (commit order is the evidence)

Both candidate levers already exist as mechanisms (T3.1c): `siting.scoreJitter` = 0.35 and
`founding.endowmentJitter` = 0.25 (uniform u ∈ [−1,1], so realised CV = amplitude/√3 ≈ 0.20
and ≈ 0.14 respectively). The reference classes below are committed before any Item 0 number
has been seen, so no class can be selected for giving a convenient answer; the diagnosis then
picks WHICH lever, and these magnitudes bound how far it may move.

**RC-1 — founding-population variation (endowment lever).** Reference class: settlement-size
distributions in Neolithic village systems (LBK site hierarchies; Near-Eastern PPN village
surveys) and ethnographic village-fission group sizes. Village systems are right-skewed
(near-lognormal rank-size), with within-region size CV commonly ~0.5–0.8; fissioning founder
groups run tens to low hundreds (30–150) against typical villages of ~100–300 — i.e. a founding
population is NOT a fixed fraction of a standard village. JUSTIFIED BAND: founding-population
CV ≈ 0.4–0.6. Shipped realised CV ≈ 0.14 sits WELL BELOW the band's floor — recorded before
measurement as the endowment lever's headroom. (If Item 0's (d) disagrees with the arithmetic
prediction of 0.14, the measurement wins and the discrepancy is investigated first.)

**RC-2 — site-quality variation among settled sites in one region (siting lever).** Reference
class: cross-SECTIONAL yield variation among farmed sites of one region in pre-modern cereal
agriculture — the same manorial corpus T3.4b used for its temporal variance (Winchester Pipe
Rolls demesne yields), read across manors instead of across years: inter-manor mean-yield
differences within one estate/county run ~±20–40% (CV ≈ 0.2–0.3), and that is among SETTLED,
farmed sites — the survivors of site selection, exactly this packet's population. JUSTIFIED
BAND: productive-capacity CV across the twelve sites ≈ 0.2–0.3. Item 0's (a) measures where
the shipped world sits against it.

**Discipline:** whichever lever the diagnosis indicts moves INTO its band and no further —
the smallest intervention Item 0 justifies. Neither band was derived from, nor may be adjusted
against, any trade observable (CR-003 §5.1).
