## §3 M7.3 contracts (revised)

**Invariants:** BASE §3's invariants and standing rules all carry. Today's decisions add four:
- **INV-1 (N7):** the authoritative battle path contains no floating-point arithmetic. A source scan enforces it (PROTO `scripts/check-proto-determinism.sh`; for integration, an extension of `scripts/check-banned-constructs.sh` to the framework's project, O-14).
- **INV-2 (N3, N5):** time is integer everywhere: campaign whole days (already `SimClock.SimDays`) and battle milliseconds on one global timeline.
- **INV-3 (N12):** entities are battle-transient. After a battle only formation counts persist, and conservation is exact.
- **INV-4 (N8):** every domain module, naval included, supports full tactical control. Auto-resolve is an option on the same contract, never the default.

Each row: what is now DECIDED, and the agent-designed mechanism under the N5/N11/N14 delegations, as prototyped in PROTO. A mechanism is binding contract text only when M7.3 is accepted. PROTO proves feasibility; it is not the shipped code.
