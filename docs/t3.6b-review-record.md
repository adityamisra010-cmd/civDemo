  transplant the reference class onto a quantity it never measured (§7.10 shape). Second,
  the site-cell compression's real consequence — identical renewable deposit channels — is
  water-hugging, which is the CORRECT behaviour by the reference class's own lights
  (Neolithic settlement DID hug water; its fish/clay access WAS uniformly high). D-025's
  siting rule therefore STANDS (ADR below).
